# Campaign Planner

Marketing Campaign Builder for Sundrift. The in-app title is Campaign Planner. Dispatch home is `/campaigns`. The Weekender simulator is `/campaign-planner/campaign/campaign_weekender_midwest`.

The Weekender baseline (9,421 sessions, 4.52% conversion, $52.37 AOV, last 180 days) is a seeded snapshot shared with Analytics. It is not a live Analytics query.

## Actions

| Action | Purpose |
| --- | --- |
| `list-campaigns` | Campaign checklist, counts, and the merchandising catalog. |
| `create-campaign` | Save a campaign from a name, keywords, and description. |
| `get-campaign` | One campaign and its current lifts. |
| `get-campaign-simulation` | Projected sessions, conversion, AOV, and revenue. |
| `update-campaign` | Save slider lifts, the window, or mark complete. |

Research similar campaigns opens the agent sidebar. Mark Complete is a local save.
